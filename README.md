# 네트워크관리사 2급 로컬 CBT

2025-11-02, 2025-08-24, 2025-05-25, 2025-02-23, 2024-11-03, 2024-08-25, 2024-05-19, 2024-02-25, 2023-11-05, 2023-08-20, 2023-05-21, 2023-02-26 필기 기출문제를 회차별로 연습할 수 있습니다. 총 12회차 600문항이며 각 회차는 50문항입니다.

## VS Code에서 실행

1. ZIP 파일을 모두 압축 해제하고, VS Code에서 **파일 → 폴더 열기**로 `network-cbt` 폴더를 엽니다.
2. VS Code 탐색기에서 `index.html`을 우클릭하고 **파일 탐색기에 표시**를 선택합니다. 파일 탐색기에서 `index.html`을 더블클릭하면 기본 브라우저에서 열립니다. 이미 Live Server 확장을 쓰고 있다면 **Open with Live Server**로 열어도 됩니다.
3. 시험 회차를 고르고 **시험 시작**을 누릅니다. **전체**를 선택하면 모든 회차의 문제 중 중복 없이 무작위로 50문항을 고릅니다.

설치나 인터넷 연결 없이 실행할 수 있습니다. `index.html`, `app.js`, `exams.js`, `explanations.js`, `style.css`, `assets`를 같은 폴더에 두세요.

## 시험 진행

- **이전**, **다음**, **문제 이동**으로 원하는 문항으로 갑니다. 이동해도 선택한 답안은 유지됩니다.
- **제출 및 채점**으로 100점 만점 점수, 정답·오답·미응답 수를 확인합니다. 각 문항에서 해당 시험의 정답 번호와 원본 문항 번호를 볼 수 있습니다.
- 채점 후 **정답·오답·미응답 모든 문항**에 정답 보기와 문항별 해설이 자동으로 표시됩니다. 맞힌 문제에는 **선택한 정답**과 그 보기가 정답인 이유가 표시됩니다. 문제 이동에서 각 번호를 눌러 복습할 수 있으며, 제출 전에는 해설이 숨겨집니다.
- 해설은 전체 600문항에 대해 별도로 작성한 학습 자료입니다. 보기 순서가 섞여도 현재 화면의 정답 번호와 연결됩니다. 원본 표현에 주의가 필요한 문항에는 차이점과 공식 참고 문서를 덧붙였습니다. 해설 자체는 오프라인에서도 읽을 수 있고 외부 참고 링크를 열 때만 인터넷이 필요합니다.
- **새 시험 / 재시작**은 선택한 회차를 다시 섞고 기존 답안을 초기화합니다. **전체**에서는 50문항을 새로 추첨합니다. 답안은 열려 있는 페이지에만 유지되므로 새로고침하거나 닫으면 초기화됩니다.

## 원본 반영

- 업로드된 학생용 HWP 열두 파일에서 총 600문항, 보기 2,400개와 회차별 정답표를 추출했습니다. 정답표 600개를 원본 보기의 정답 표기와 대조했습니다.
- 문항과 보기를 식별하는 번호는 화면의 순서에 맞춰 붙입니다. 본문과 보기 문구는 유지하고, 원본에서 보기를 열로 나누던 탭과 보기 앞뒤 여백을 정리했습니다. 과목명은 각 문제에 함께 표시합니다.
- 2025-11-02, 2025-08-24, 2025-05-25 회차는 각각 원본 GIF 7개, 2025-02-23 회차는 9개를 담았습니다. 2024-11-03은 9개, 2024-08-25는 10개, 2024-05-19는 12개, 2024-02-25는 9개로 2023년 네 회차의 39개를 포함해 전체 그림은 109개입니다. 그림에 포함된 도식과 표도 이미지에 남아 있습니다. HWP의 과목 제목과 정답표는 웹 화면의 과목 표시와 채점 데이터로 옮겼습니다.
- 채점 기준은 원본 정답표를 유지합니다. 예를 들어 2024-05-19 원본 1번의 DF Flag와 단편화 구분 필드, 2024-02-25 원본 42번의 재귀·반복 질의처럼 원본 정답이나 표현에 주의가 필요한 내용은 해설에 정확한 개념을 따로 적었습니다.
- 문제 출처는 원본 HWP에 표시된 전자문제집 CBT (www.comcbt.com)입니다.

- 2023년 4회차 200문항과 원본 그림 39개를 추가했습니다. 2023-11-05 14번·40번, 2023-05-21 38번은 원본 정답표와 기술적 설명의 차이를 해설과 참고 문서에 표시했습니다.
